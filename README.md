# 🌦️ PRODIGY_WD_05

Weather App – Prodigy InfoTech Web Development Internship Task 05

---

## 📌 Project Overview

This project is a **Weather Web Application** developed as part of the  
**Prodigy InfoTech Web Development Internship (Task 05)**.

The application allows users to:
- 🌍 Enter a city/location name  
- ☁️ Fetch real-time weather data using a weather API  
- 🌡️ View current temperature and weather conditions  
- ⏱️ See the last updated time  

This project focuses on **API integration, JavaScript logic, and responsive UI design** using **HTML, CSS, and JavaScript**.

---

## ✨ Features

- 🔍 Search weather by city name  
- 🌡️ Displays current temperature  
- ☁️ Shows current weather condition  
- 💧 Displays additional details like humidity and wind speed  
- ⏱️ Shows last updated time  
- 📱 Fully responsive design  
- 🎨 Clean and user-friendly interface  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Logic and API integration  
- **Weather API** – Fetching real-time weather data
